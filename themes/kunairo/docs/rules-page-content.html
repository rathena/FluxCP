Al jugar en KunaiRO aceptas cumplir con las siguientes reglas. El incumplimiento puede resultar en sanciones temporales o permanentes.

El equipo de administración se reserva el derecho de modificar estas reglas en cualquier momento.

⛔

Conducta General

  1. Trata a todos los jugadores y miembros del staff con respeto.
  2. Está prohibido el acoso, discriminación, amenazas o cualquier forma de hostigamiento.
  3. No se permite contenido NSFW, político o religioso en canales públicos.
  4. No hagas spam en el chat público ni por PM.
  5. Está prohibido hacerse pasar por un GM o miembro del staff.
  6. Las decisiones de los GMs son finales. No discutas sanciones en público — usa el sistema de tickets.
🚫

Trampas y Software Ilegal

  1. Está estrictamente prohibido usar bots, macros, auto-clickers o cualquier automatización.
  2. No se permiten speed hacks, fly hacks, zoom hacks ni ningún tipo de hack.
  3. Está prohibido usar clientes modificados que alteren la jugabilidad.
  4. No se permite el uso de packet editors o herramientas de inyección.
  5. Sanción: Ban permanente sin previo aviso.
💰

Comercio y Economía

  1. Está prohibido el RMT (Real Money Trading) — comprar o vender items/zeny/cuentas por dinero real.
  2. No se permiten estafas de ningún tipo. Los trades son responsabilidad de cada jugador.
  3. Está prohibido duplicar items o explotar bugs de la economía.
  4. No se permite la manipulación de mercado mediante cuentas múltiples.
  5. Sanción: Ban permanente de todas las cuentas involucradas.
⚔

War of Emperium (WoE)

  1. Máximo 1 cliente por persona durante WoE (sin multiclient).
  2. Está prohibido usar alianzas no declaradas entre guilds enemigas.
  3. No se permite sabotear tu propia guild (spy/infiltración maliciosa).
  4. Los AFK characters dentro del castillo durante WoE serán removidos.
  5. Usar bugs o exploits durante WoE resulta en descalificación y ban temporal.
👥

Multiclient

  1. Se permiten hasta 2 clientes simultáneos fuera de WoE.
  2. Durante WoE solo se permite 1 cliente.
  3. Está prohibido usar multiclient para farmear MVPs (holdear/tanquear con alts).
  4. No se permite usar alts para buff slave en PvP/BG.
🐛

Bug Abuse

  1. Si encuentras un bug, repórtalo inmediatamente al staff via ticket o Discord.
  2. Explotar bugs intencionalmente resulta en ban permanente.
  3. Reportar bugs de forma responsable puede ser recompensado.
  4. No publiques bugs en canales públicos — usa el sistema privado de reportes.
